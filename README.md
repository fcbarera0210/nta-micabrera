# NTA Mica Cabrera

Sitio web de Mica Cabrera — Nutricionista. Acompañamiento integral (consultas online y presenciales), recetario y reserva de horas.

## Requisitos

- Node.js 18+
- npm

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en el navegador.

## Build

```bash
npm run build
```

## Producción

```bash
npm run start
```

## Deploy en Vercel

Conecta este repositorio en [Vercel](https://vercel.com): **Import Project** → elige el repo `fcbarera0210/nta-micabrera`. Vercel detecta Next.js y usa `next build` por defecto; no hace falta configuración adicional.
